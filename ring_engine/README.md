# ring_engine

The code for AtlanteanConstructor: the centre-pivot rig (`simulation_runner.py`)
and the tethered EOx trencher (`tether_sim.py`, `compare_sites.py`), on a shared
terrain engine. Run every command from this directory.

The project README covers both rigs, the model, the results, the commands and
what each file does: [../README.md](../README.md).
